## 🌟 Overview

This portfolio website highlights Gagana's authentic academic background, technical skills, verified programming expertise levels, real projects, and career aspirations. Built strictly with **Vanilla HTML5, CSS3, and JavaScript** with zero third-party framework overhead, ensuring instant loading, high accessibility, and complete cross-device responsiveness.

### 🎨 Visual Theme & Aesthetics
- **Color Palette:** **Electric Sunset & Ember Charcoal** (Default)
- **Design Style:** Modern Developer Portfolio with frosted glassmorphism cards and ambient radial mesh lighting.
- **Appearance Modes:** Default **Light Theme** with instant toggle to **Dark Mode** (saved in `localStorage`).
- **Interactive Multi-Palette Engine:** 4 customizable accent color themes (`Electric Sunset`, `Cyber Violet`, `Emerald Tech`, `Ocean Azure`).
- **Hero Presentation:** Text-focused introduction featuring live Indian Standard Time (IST) clock for Udupi, Karnataka, and an interactive terminal snapshot.

## 💻 Quick Start & Preview

No build tools, bundlers, or package installations are required!

### Option 1: Direct File Open
Double-click `index.html` or open it directly in any web browser:
```
file:///c:/Users/Administrator/Desktop/gagana/index.html
```

### Option 2: Local HTTP Server (Optional)
If you prefer running a local development server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js (npx)
npx serve .
```
Then visit `http://localhost:8000` in your browser.
